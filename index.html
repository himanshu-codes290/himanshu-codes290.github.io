PrivateRedact

live

Permanently redact PDFs in the browser. Nothing is uploaded, because there is no server.

  • Deletes text under a box glyph by glyph from the PDF content streams instead of painting over it. Neighbouring text keeps its exact position.
  • Also strips text inside form XObjects, images fully inside a box, touching annotations and form fields, metadata, bookmarks, attachments and JavaScript.
  • Re-opens its own output with a second, independent engine (PDF.js) to confirm no extractable text remains. Partly covered images and scanned pages are flagged, not silently marked done.
  • Runs in a Web Worker behind a Content-Security-Policy that blocks every network request. Installable as an offline PWA. CI runs format, lint, typecheck, tests with coverage, and build.

DocMind

in progress

Multi-tenant document intelligence with measurable accuracy, not a chat demo.

  • Uploads invoices and contracts, chunks and embeds them, then extracts structured fields that are validated against a JSON Schema plus semantic checks (line items sum to the total, dates parse) before anything is persisted.
  • Answers questions with hybrid retrieval: PostgreSQL full-text search fused with pgvector similarity (Reciprocal Rank Fusion), streamed token by token over Server-Sent Events.
  • Every query is tenant-scoped through a JWT claim and an EF Core global filter. Every sensitive action lands in an append-only audit log. PostgreSQL doubles as the job queue.
  • An eval harness runs extraction over labelled fixtures in CI and fails the build if accuracy drops below the committed baseline, so prompt edits are measured, not guessed.
